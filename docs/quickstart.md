# Быстрый старт: веб-интерфейс

Это руководство для того, кто запускает приложение впервые и хочет за пять минут
понять, что где нажимать. Сам интерфейс — это `streamlit_app.py`; он обучает
модель сегментации дефектов на смеси реальных и синтетических данных и показывает,
помогает ли синтетика.

## Что понадобится

- Python 3.11 или 3.12 (TensorFlow 2.19 ещё не поддерживает 3.13) и
  [Poetry](https://python-poetry.org/). Установка зависимостей:
  ```bash
  poetry install
  ```
  Poetry создаст локальное окружение `.venv` прямо в папке проекта и поставит
  туда всё (включая `streamlit` и `tensorflow`). Если в системе несколько версий
  Python, заранее укажите нужную:
  ```bash
  poetry env use 3.12
  ```
- Датасет в формате «папка с двумя подпапками»:
  - `images/` — снимки (`image0.jpg`, `image1.jpg`, …);
  - `bitmaps/` — маски дефектов (`bitmap0.jpg`, …), парные по номеру.

  Если ничего своего нет — в репозитории лежит `example_datasets_scratches/`, и
  поля путей по умолчанию указывают именно на него. То есть приложение можно
  запустить и сразу нажать «Запустить», ничего не настраивая.

## Запуск

Из папки проекта:

```bash
poetry run streamlit run streamlit_app.py
```

(или `poetry shell`, а затем просто `streamlit run streamlit_app.py`).

Откроется вкладка браузера (по умолчанию `http://localhost:8501`). Если нет —
адрес будет напечатан в терминале.

## Язык

В левой панели — селектор **«Язык интерфейса»**. По умолчанию русский;
переключение на English мгновенно перерисовывает всё: подписи, кнопки,
подсказки и пункты выпадающих списков. Никаких перезапусков не нужно.

## Первый прогон за минуту

Полный перебор обучает 11 моделей подряд и на процессоре идёт долго. Чтобы
быстро убедиться, что всё работает, не дожидаясь получаса:

1. Откройте вкладку **«Обучение»**.
2. В поле **«Режим»** выберите *Один прогон (single)*.
3. Поставьте **«Лимит изображений»** = 16, **«Количество эпох»** = 1,
   **«Размер тестовой выборки»** = 4.
4. Ползунки **«Доля реальных»** и **«Доля синтетики»** оставьте, например, по 0.5.
5. Нажмите **«Запустить обучение»**.

Появится прогресс-бар по эпохам, затем таблица метрик, график и несколько
примеров предсказаний. На этом маленьком наборе цифры будут плохими — это
нормально, цель прогона техническая.

Когда захотите настоящий результат — верните лимит в 0, режим *Перебор доли
синтетики (sweep)*, эпох 8–15, и запаситесь временем (или видеокартой).

## Вкладки

### Обучение
Главная вкладка. Поля сверху вниз:

- **Папка реальных / синтетических данных** — пути к датасетам (у каждого свои
  `images/` и `bitmaps/`).
- **Режим**:
  - *Перебор доли синтетики (sweep)* — обучает модели с долей синтетики
    0 %, 10 %, …, 100 % и строит зависимость качества от доли. Это основной
    сценарий «проверить, помогает ли синтетика».
  - *Один прогон (single)* — одна модель с долями, которые вы задаёте ползунками.
- **Количество эпох**, **Размер батча** — обычные параметры обучения.
- **Размер тестовой выборки** — сколько реальных изображений отложить под тест.
  Они не попадают в обучение, поэтому метрики честные (без утечки).
- **Лимит изображений** — обрезает датасеты до N штук. `0` — без ограничения;
  любое другое значение полезно для быстрых прогонов на процессоре.
- **Доля реальных / Доля синтетики** — появляются только в режиме *single*.
- **Дополнительные параметры** (сворачиваемый блок): порог бинаризации маски,
  learning rate, seed.

Кнопка **«Предпросмотр датасета»** ничего не обучает — просто показывает,
сколько нашлось картинок, и несколько пар «снимок / маска», чтобы убедиться,
что пути и структура верные. Делайте это перед долгим прогоном.

Результаты прогона автоматически сохраняются в `results/run_<время>.json`.

### Контуры
Отдельный инструмент: загрузите bitmap дефекта, выберите в списке **«Что
извлечь»** (контуры, ограничивающие прямоугольники или и то и другое) и нажмите
**«Извлечь»**. Вы увидите наложение на маску и сможете скачать CSV. Имена файлов
с кириллицей (`bitmap0_14_царапины.jpg`) читаются корректно.

### Результаты
Открывает сохранённый ранее `results/*.json` и строит график IoU/Loss по долям
синтетики — без повторного обучения. Удобно сравнивать прошлые прогоны.

### Справка
Та же информация, что и здесь, встроена прямо в приложение и тоже переключается
по языку.

## Если что-то идёт не так

- **«Путь не найден…»** — в указанной папке нет подпапки `images/`. Проверьте
  структуру датасета.
- **Обучение «висит»** — оно идёт в том же процессе, что и интерфейс: пока модель
  учится, вкладка занята, а прогресс виден по бару эпох. На CPU это медленно,
  особенно в режиме sweep (11 моделей). Уменьшите эпохи и поставьте лимит
  изображений.
- **Хочется быстрее** — обучение использует GPU автоматически, если TensorFlow
  видит видеокарту. Иначе работает на CPU.
